# figures

Placeholder directory for figures exported from the GPU runs:

- `pareto_latency.png` — faithfulness vs.\ P95 latency (6 cells)
- `pareto_cost.png` — faithfulness vs.\ cost per query (6 cells)
- Optional: `abstention.png` — rejection rate per cell

These are produced by `results/report.html` (static, inlined SVG can be
converted to PNG) or regenerated manually once `results/*/scorecard.json`
exists.
