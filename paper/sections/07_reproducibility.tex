\section{Reproducibility}
\label{sec:repro}

\textbf{Artifacts.}
Every finished cell writes, under \texttt{results/<cell\_id>/}:

\begin{itemize}
    \item \texttt{manifest.json}---configuration, corpus size, pricing
          version, git revision, hardware;
    \item \texttt{queries.jsonl}---one runtime record per query
          (question, answer, contexts, retrieved ids, gold ids, latency,
          TTFT, tokens, cost, label, extra fields);
    \item \texttt{scorecard.json}---aggregate summary, retrieval metrics,
          adjusted accuracy, RAGAS faithfulness, gate outcomes, judge and
          generator serve identifiers.
\end{itemize}

\texttt{queries.jsonl} and \texttt{scorecard.json} are committed
artifacts; re-running a cell deletes its own \texttt{queries.jsonl}
first, so partial output is never mixed with a fresh run. Cross-cell
summary and statistics are generated by
\texttt{analysis/scorecard.py} into
\texttt{results/scorecard\_summary.md}, and a static report is rendered by
\texttt{analysis/report.py} into \texttt{results/report.html}. Traceable
per-query artifacts respond to broader calls for provenance-aware,
reproducible RAG evaluation~\cite{brown2025systematic,murugaraj2025ragvue,saadfalcon2023ares,sharma2025survey}.

\textbf{Checks before the GPU ladder.}
\texttt{tools.selfcheck} runs nine CPU checks covering retrieval,
metrics logging, the pipeline, the cell gates, the matrix, data loading,
the retriever, and the CRAG evaluator; every gate condition is verified
to fire when broken. No cell had run before this paper was written, so
Tables 3--8 contain ``--'' placeholders and await the GPU matrix.

\textbf{Availability.}
The harness, configs, vendor data, and this paper's source are at
\url{https://github.com/Khoa-NguyenAnh-Hoang/slm-rag-bench}
(placeholder DOI to be assigned at release). Costs assume
\texttt{configs/pricing.yaml}; two renter-specific values
(\texttt{serve.gpu\_memory\_utilization} and
\texttt{gpu\_usd\_per\_hour}) must be set before a rented-box run and are
recorded in every manifest.
